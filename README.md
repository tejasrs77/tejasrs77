### 📊 Finance ETL & Analytics

**Incremental Financial Data Pipeline & Analytics Platform**

A production-style data engineering project that transforms raw financial transaction records into structured datasets for analytics and reporting.

**Key Highlights**

- Processes approximately **200,000 synthetic financial transactions**.
- Implements Python and Pandas-based ingestion, validation, and transformation.
- Uses a MySQL star schema with **Slowly Changing Dimension Type 2 (SCD-2)** customer history.
- Implements incremental loading with watermarks, upserts, checksums, and batch inserts.
- Uses transactional rollback and analytical indexing to improve reliability.
- Includes **49 automated pytest tests**.
- Provides FastAPI services and a React-based analytics interface.

**Tech Stack:** `Python` `Pandas` `MySQL` `SQLAlchemy` `Pytest` `FastAPI` `React`

### 👁️ VisionGuard AI

**Computer Vision, Visual Geometry & Inference Optimization**

A modular computer vision project exploring deep learning-based perception, object tracking, classical computer vision, and motion estimation.

**Key Highlights**

- Implemented YOLOv8 object detection for image and video processing.
- Integrated ByteTrack to assign consistent object identities across video frames.
- Explored instance segmentation and human pose estimation.
- Exported YOLOv8n to ONNX and benchmarked inference against PyTorch on an AMD Ryzen 5 CPU.
- Reduced average model inference latency from **168.52 ms to 94.56 ms**, approximately a **1.78× speedup** in the measured benchmark.
- Implemented experiments involving camera calibration, ORB feature matching, essential matrices, relative camera pose, and triangulation.
- Explored synthetic visual odometry for camera trajectory estimation.
- Implemented a separate Kalman filtering experiment for noisy 2D motion measurements.

**Note:** Visual odometry and Kalman filtering evaluations use synthetic data and are experimental modules rather than a fully integrated real-world system.

**Tech Stack:** `Python` `OpenCV` `YOLOv8` `ByteTrack` `PyTorch` `ONNX Runtime` `NumPy`
