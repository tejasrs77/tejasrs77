## About me

I'm Tejas. I build projects that connect data pipelines, machine learning models, and application interfaces. My work explores healthcare record retrieval, aircraft-engine predictive maintenance, financial reconciliation, and transaction processing.

I'm interested in how data engineering and applied AI can make information easier to find, understand, and use.

## Featured projects

### EHR Insight and Clinical Validator

An educational healthcare RAG application for exploring a selected patient's historical records through a conversational interface.

- **Implementation:** Patient-scoped semantic retrieval with clinical embeddings, PII redaction using Microsoft Presidio, and response controls using NVIDIA NeMo Guardrails.
- **Application:** Streamlit interface backed by FastAPI and PostgreSQL vector search.
- **Stack:** Python · FastAPI · Streamlit · PostgreSQL · pgvector · Docker · AWS

[View repository →](https://github.com/tejasrs77/EHR-Insight-and-clinical-validator)

### AeroGuard AI

A predictive maintenance project exploring aircraft-engine reliability using NASA C-MAPSS turbofan data.

- **Focus:** Machine learning for predictive maintenance, paired with a grounded reliability copilot.
- **Data and methods:** NASA C-MAPSS · Machine learning · Grounded AI assistance

[View repository →](https://github.com/tejasrs77/aeroguard-ai)

### FinRecon AI

A financial reconciliation application for investigating discrepancies and potential revenue leakage.

- **Focus:** AI-powered reconciliation and anomaly detection, with a control-tower dashboard for exploring financial discrepancies.
- **Methods and interface:** Financial reconciliation · Anomaly detection · Dashboard

[View repository →](https://github.com/tejasrs77/finrecon-ai)

### Finance ETL

A data engineering project exploring how raw financial transactions become structured information for analysis.

- **Focus:** Financial transaction pipelines and the transformation of raw data into an analytical format.
- **Methods:** ETL · Transaction processing · Data transformation

[View repository →](https://github.com/tejasrs77/finance-etl)
